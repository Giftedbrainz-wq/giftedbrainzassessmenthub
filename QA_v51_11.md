## Not yet validated

- **Live** Supabase migration (please run against the correct project), actual Supabase Storage uploads, real Groq scoring and delivery through EdgeOne.

- Out-of-page notification delivery is intentionally not built; participant in-page polling and opt-in browser notification are supported only while the result page is open.
- Browser-stored device IDs are not tamper-resistant proof of identity.

## Production smoke tests

1. Run migration and check `/api?action=health` reports `databaseOk` and `aiConfigured` true.
2. Admin logs in, creates draft, adds image, optionally adds video, and publishes.
3. Visit share link on a phone; start challenge, type a written answer; verify no timer and autosave.
4. Submit and save personal result link. Reopen public link from same device; verify it offers the saved submission and prevents a duplicate.
5. Before release, verify result contains no answer or score. After release, verify grade and official answer become available only with valid result token.
6. Review the AI feedback in admin; edit score; check result reflects updated mark.
7. Import a question with I–IV and a later "Which ..." clause, and confirm roman alignment and separated follow-up on a narrow screen; import a text containing a second numbered question and verify it is flagged for manual splitting.
