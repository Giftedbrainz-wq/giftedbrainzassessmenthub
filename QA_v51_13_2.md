# Gifted Brainz Assessment Hub v51.13.2 — Local QA summary

## Static and mock tests that passed

- `npm run check` — all `app.js`, Daily Challenge, server API, renderer and draft JS pass Node syntax checks.
- Browser simulation at 1200px desktop and 390px mobile:
  - Challenge start shows the tab-switch rule.
  - Two background visibility events count as 1/3 and 2/3 warnings; the original typed answer and paragraph breaks survive DOM redraw.
  - Third background event automatically submits `forfeited:true`; successful request shows a permanent result link.
  - Student-side live answer/LaTeX preview is absent. Admin previews remain.
  - Administrator lists show Delete rather than Archive; pressing Delete sends the required `permanent:true` request (after confirmation).
  - Results display question, student answer, official answer, real HTML tables and separate feedback cards.
  - Download PDF exporter selects a faithful DOM clone of all visible result cards and removes buttons, help text and browser links.
- Mock EdgeOne backend API test (`qa_security_api_v51_13_2.mjs`):
  - Forfeited submissions receive a 0-mark reviewed result, without AI provider calls.
  - Lost-response retry with the same token creates only one submission.
  - A released result displays the stored score immediately.
  - Deletion requires admin authentication and explicit permanent confirmation; it issues DELETE rather than archival PATCH.
- Browser-printed sample PDF rendered and visually inspected: separate question/answer/feedback cards, legible typography, clear A4 pagination. Adjusted CSS to prevent splitting short feedback cards between pages.

## Not tested against live services

- The true Supabase foreign-key cascade after running `schema_daily_challenge_delete_v51_13_2.sql` (local mock simulated it).
- Real EdgeOne deployment, production authentication and real AI grading.
- Actual CDN-based `html2pdf.js` output, because CDN fetch is unavailable in this test environment. The exporter was checked using an intercepted HTML-to-PDF library call, and browser-native PDF print rendering was visually inspected.
- Tamper-resistance of browser tab visibility. It is inherently bypassable in an ordinary website and may differ by browser/device.
