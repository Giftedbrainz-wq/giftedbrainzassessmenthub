## Operational notes

- Weak-area reports use the existing **topic label saved with each question**; generic/blank topic labels can only yield general subject-focused revision. They do not use a generative AI service, make predictions about student ability, or infer mastery from one question.
- Subject combination enforcement is implemented server-side; clients cannot obtain, submit or have scores calculated for unselected sections. Administrators must ensure each subject section contains questions before publication.
- Current features rely on existing Supabase schema and existing approved credentials; no access to live secrets was available for local testing.
